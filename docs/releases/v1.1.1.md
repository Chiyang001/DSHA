# DSHAN 1.1.1

Deepseek Harness for Android Native

## 更新内容

- 项目统一更名为 DSHAN（Deepseek Harness for Android Native），更新桌面名称、启动页、引导页、通知、设备连接名称和文档。包名保留为 `app.dsh.android`，支持覆盖安装。
- 1.1.1 附件更新为更名后的 `DSHAN-1.1.1.apk`。

- Android 插件适配：glob / grep 无需 Linux 二进制，统一应用于各预设；禁用不可用的桌面工具，保留权限预设服务。
- 文件打开支持图片、PDF、系统打开方式，以及 ESM / CommonJS 插件。
- 安装向导和 Android 设置新增 Root 检测与模式开关、悬浮窗权限管理、可跳过的虚拟副屏配置。
- 虚拟副屏可创建、关闭，并允许 DeepSeek 按需管理；应用启动解析显式组件并检查副屏前台任务。
- 中文输入通过内置 Unicode 输入法，支持混合文本、标点、Emoji 和换行，输入后恢复原键盘。
- 副屏输入核对实际输入连接的显示 ID、UID、PID 和焦点版本，避免把主屏键盘窗口误判为主屏输入目标。

## 验证

- 59 项 JavaScript 自动化测试通过，Android APK 构建通过。
- OPPO PKQ110 / Android 16 / Shizuku 真机：glob、grep、设置/B 站/微信副屏启动通过；主屏及副屏 22 的 Unicode 输入、原键盘恢复通过。
- 未 Root 手机的检测及禁止启用 Root 模式通过；Root 真机执行尚未验证。

## 安装与限制

- Android 11+，arm64-v8a。附件沿用此前版本的 debug 签名，versionName 1.1.1 / versionCode 2。
- 设备操作需 Shizuku 或已授权 Root；设备控制、任意 shell 和 AI 副屏管理分别授权。
- 副屏截图仍需 Android 14+ 和 Shizuku，部分应用受系统多屏策略限制。
- grep 使用 JavaScript 正则，与 ripgrep 方言不同；外部 Node / pnpm 工作流及桌面工具不可用。
